# 💈 BarberPro

**Plataforma de agendamento para barbearias.**

O BarberPro é um projeto de aplicativo desenvolvido para conectar clientes, barbeiros e proprietários de barbearias em uma única plataforma.

## 🚀 Funcionalidades

- Cadastro e autenticação de usuários.
- Cadastro e gerenciamento de barbearias.
- Cadastro e gerenciamento de barbeiros.
- Gerenciamento de serviços e preços.
- Agendamento de horários.
- Área do cliente para acompanhar agendamentos.
- Estrutura preparada para múltiplas barbearias.

## 🛠️ Tecnologias

- React Native
- Expo
- JavaScript
- Supabase
- PostgreSQL

## 📱 Projeto

O BarberPro está em desenvolvimento, com foco em usabilidade, organização e expansão para múltiplas barbearias.
